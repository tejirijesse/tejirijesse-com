## Consequences

The stated advantage is that the system does not panic. The corresponding
weakness is that it cannot be frightened by something it has never seen. Human
panic is sometimes correct — it is a crude detector for regime changes that a
model trained on the previous regime has no representation for. Removing it
removes both the noise and the signal.

The second-order risk is about the transparency layer specifically. A public,
verifiable track record is a discipline while returns hold, and it becomes an
incentive to manage the visible number when they do not. Making a record public
changes the behaviour of the thing being recorded. That is true of every system
on this site, and this is the one where I can watch it happen to me.
